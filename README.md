# Car Price Prediction with Machine Learning

## Overview

This project is a Machine Learning regression system developed as part of the CodeAlpha Data Science Internship. The objective of the project is to predict the selling price of used cars based on various features such as the car's age, mileage, fuel type, transmission, and engine capacity.

The project implements a Random Forest Regressor (or alternative regression algorithms) to perform the price estimation task. The complete workflow includes data cleaning, feature engineering, exploratory data analysis (EDA), model training, hyperparameter tuning, and evaluation.

## Features

* Data preprocessing (handling missing values, encoding categorical variables, and feature scaling)
* Detailed Exploratory Data Analysis (EDA) and data visualization using correlation heatmaps and distribution plots
* Machine Learning model training using advanced regression techniques
* Model evaluation using Mean Absolute Error (MAE), Mean Squared Error (MSE), and R-squared ($R^2$) Score
* Model saving for future deployment and integration
* Prediction of car prices based on user-defined vehicle specifications

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Project Structure

* `dataset/`: Stores the car price dataset file (e.g., CSV format)
* `models/`: Stores the trained Machine Learning regression model
* `outputs/`: Stores generated visualizations, residual plots, and evaluation metrics
* `src/`: Contains the project source code
* `main.py`: Main execution file for running the entire pipeline

## Results

The trained model achieves low error rates and a high $R^2$ score on the test dataset, demonstrating strong capability in accurately predicting used car market prices based on historical trends.

## Learning Outcomes

* Practical understanding of Regression Algorithms and Continuous Target Prediction
* Feature Engineering techniques (One-Hot Encoding, Label Encoding, and Feature Scaling)
* Data Visualization and correlation analysis for numerical data
* Model Evaluation using regression-specific performance metrics
* Building End-to-End Machine Learning workflows for business-centric problems
